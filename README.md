Python Libraries Mini Project Collection
This repository is a collection of mini projects and practice scripts demonstrating core Python data analysis skills.
It covers NumPy, Pandas, Matplotlib, Seaborn, data preprocessing, and basic EDA on multiple datasets.

📌 Key Skills Demonstrated
NumPy → Arrays, mathematical operations, aggregations.

Pandas → Data cleaning, filtering, grouping, aggregation, subsetting.

Matplotlib & Seaborn → Visualizing trends, distributions, correlations.

EDA → Extracting insights from real datasets.

Basic Preprocessing → Handling missing values, type conversions.
# Clone the repository  
git clone https://github.com/mahima638/python-libraries-mini-project.git  

# Navigate into the folder  
cd python-libraries-mini-project  

# Install dependencies  
pip install -r requirements.txt  

# Run a project  
python Movie_analysis/src/movie_analysis.py
